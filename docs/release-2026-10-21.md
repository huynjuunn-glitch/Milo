This is not a zero-advisory audit. `npm ls --omit=dev` locates all six under Astro's build/tooling graph; npm's production dependency category does not imply that these Node packages run on this static deployment.

| Package | Relevant boundary and current mitigation |
| --- | --- |
| sharp 0.35.4 | The advisory concerns SVG decoding through librsvg, particularly glibc Linux. There is no public image-processing server. Reference generation uses repository-owned JPEG/PNG inputs and controlled generated SVG strings, not visitor SVG. Visitor images use native browser decoding. Do not introduce remote/untrusted SVG build inputs before patching. |
| http-cache-semantics 4.2.0 | No Node shared-response cache or visitor session service is deployed. Static HTML/assets are served by Cloudflare, not this package. |
| source-map-js 1.2.1 | Local build source-map processing only; public visitors cannot submit indexed maps to a Node service. |
| undici 8.10.0 | Build font/network tooling under unifont; no deployed Node HTTP/WebSocket proxy, shared credential cache or visitor-specified URL fetcher. |
| vite 8.1.4 | Build and local development tooling only. No public Vite development server or open-in-editor endpoint is deployed. |
| smol-toml 1.8.0 | Trusted repository/config parsing during tooling, not a public TOML ingestion endpoint. |
